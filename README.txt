Hotkeys для Windows 10/11 x64

1. Завершите старую версию через Ctrl+Alt+Q.
2. Запустите Hotkeys.exe. Установка Python не требуется.
3. Программа работает, пока окно открыто; крестик завершает её работу.
Шаблоны: %APPDATA%\HotkeysTemplateEditor\templates.json
Для функций Excel нужен установленный Microsoft Excel.
Полная инструкция: HOTKEYS_README_RU.md в архиве.
