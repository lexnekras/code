# Hotkeys: редактор шаблонов и системный трей

Шаблоны создаются и редактируются в окне программы. Постоянный Word-файл и установленный Word не нужны. Обработчики Excel требуют установленного Microsoft Excel.

## Запуск на Windows

1. Закройте прежнюю версию через **Ctrl+Alt+Q**, чтобы она освободила горячие клавиши.
2. Установите Python 3.10 или новее с компонентом Tcl/Tk (в обычном установщике Python он включён). Рекомендуется Python 3.12.
3. Один раз установите зависимости:

   ```powershell
   py -m pip install pywin32 pyperclip
   ```

4. Откройте **`hotkeys_with_template_editor.pyw` двойным щелчком**. Консоль не создаётся; программа запускается сразу в системном трее рядом с часами. Если значка не видно, откройте стрелку **^** со скрытыми значками Windows.
5. Нажмите значок **«Hotkeys — мои шаблоны»** или **Ctrl+Alt+R**, чтобы открыть редактор.

Из командной строки используйте запускатель без консоли:

```powershell
pyw hotkeys_with_template_editor.pyw
```

Вариант `.py` автоматически запускает отдельный процесс через `pythonw.exe` и завершает консольную копию. При двойном щелчке по `.py` консоль может кратко появиться до перезапуска; для запуска без её появления выбирайте именно `.pyw`. Уже открытое вами окно PowerShell/командной строки программа не скрывает и не закрывает.

При отсутствии зависимостей или другой ошибке запуска отображается сообщение Windows. Новые сторонние зависимости для значка трея не нужны.

## Редактирование

- Выберите слева слот **Ctrl+1…Ctrl+9**.
- Введите или вставьте многострочный текст справа. Для вставки доступны **Ctrl+V**, кнопка **«Вставить из буфера»**, меню **«Правка → Вставить»** и меню по правой кнопке мыши.
- Обработка Ctrl+C/X/V/A/Z/Y/S в редакторе на Windows использует физические клавиши и поддерживает русскую и английскую раскладки.
- Кнопки `{clip}`, `{clip1}`…`{clip4}` вставляют подстановку в позицию курсора. При использовании шаблона `{clip}` заменяется текущим текстом буфера, остальные — предыдущими записями истории. История ограничена пятью непустыми текстовыми записями и не сохраняется между запусками; при пустом текущем буфере `{clip}` будет пустым, а `{clip1}` — последней непустой записью.
- Нажмите **«Сохранить»** или **Ctrl+S**. Изменения применяются сразу; перезапуск не нужен.
- **«Отменить изменения»** возвращает последнее сохранённое состояние всех слотов.
- **«Очистить этот шаблон»**, затем **«Сохранить»** освобождает соответствующее сочетание клавиш.
- Если сочетание занято другой программой, редактор показывает его в предупреждении и в строке шаблона.

При редактировании несохранённые тексты сохраняются в черновике при переключении между слотами. Закрытие окна предлагает сохранить, отбросить правки или отменить закрытие. При ошибке записи черновик остаётся в редакторе, а ранее сохранённые настройки и активные шаблоны не заменяются.

## Работа в системном трее

| Сочетание | Действие |
|---|---|
| Ctrl+1…Ctrl+9 | Вставить соответствующий сохранённый шаблон в активную программу |
| Ctrl+Alt+R | Открыть редактор шаблонов |
| Ctrl+Alt+D | Вставить содержимое буфера в новую книгу Excel |
| Ctrl+Alt+L | Очистить выделение в активном Excel |
| Ctrl+Alt+Q | Завершить программу |

В самом редакторе цифровые сочетания выбирают соответствующий шаблон, не вставляя его в текст. Цифровой блок справа на клавиатуре по умолчанию отключён, как в прежней версии (`REGISTER_NUMPAD = False`).

При запуске программа показывает только значок в трее. **«Убрать в трей»** и крестик закрывают окно редактора, сохраняя работу горячих клавиш. Если есть несохранённые изменения, программа предложит сохранить их, отбросить или отменить закрытие.

- Щелчок по значку или **Ctrl+Alt+R** — открыть редактор.
- Правая кнопка по значку — меню **«Открыть редактор» / «Выход»**.
- **«Выход»**, **«Завершить программу»** или **Ctrl+Alt+Q** — остановить программу и убрать значок.

Значок восстанавливается после перезапуска Проводника Windows. Если создать значок не удаётся, редактор автоматически открывается и показывает сообщение. Если одновременно недоступны значок и сочетание открытия, окно остаётся доступным через панель задач.

## Перенос прежних шаблонов

В меню **«Программа → Импортировать старые шаблоны из Word…»** выберите прежний `.docx`. Первые девять непустых абзацев станут шаблонами 1–9. Абзацы внутри таблиц не импортируются. Тексты появятся как несохранённые изменения: проверьте их и нажмите **«Сохранить»**. Исходный Word-файл не изменяется и после переноса программе не нужен.

## Где хранятся данные

После сохранения программа сама создаёт файл:

```text
%APPDATA%\HotkeysTemplateEditor\templates.json
```

Редактировать этот файл вручную не требуется. Он хранится отдельно от скрипта, поэтому замена файла программы не стирает шаблоны. Для резервной копии достаточно сохранить папку `HotkeysTemplateEditor`. Запись настроек выполняется через временный файл с последующей заменой. Если сохранённый файл повреждён, программа сообщает об ошибке и не перезаписывает его.

## Проверки и ограничения

Проверки хранения данных, Unicode и переносов строк, импорта DOCX, черновиков, ошибок сохранения, закрытия и выхода, кнопок подстановок, вставки из буфера, управления регистрациями, перезапуска через pythonw и жизненного цикла трея находятся в `test_hotkeys_editor.py`:

```powershell
py -m unittest discover -s . -p "test_*.py" -v
```

Интерфейс проверен на Linux с виртуальным экраном и Tk 8.6/9.0. В тестах Windows API заменён имитацией: настоящее создание значка трея, запуск без консоли, доставка глобальных горячих клавиш и взаимодействие с Excel COM требуют проверки на Windows.

В Excel-обработчиках сохраняются ранее выявленные риски замены формул значениями при преобразовании диапазонов и неполного соблюдения `CLEAN_FORMULAS`. Они требуют отдельного исправления перед обработкой рабочих книг с формулами. Вставка шаблонов, как в исходном скрипте, сохраняет только текст буфера обмена, а не изображения, HTML и форматы Excel.
